134:Physical capacitor type 36: let Ncharge=trunc32(60*charge_seconds), Ndischarge=trunc32(60*discharge_seconds), c/d be integer counters, q the stored Boolean. On any input change, clear both counters. If q=0 and A=1, test c==Ncharge, set q=1 if equal, then increment c. If q=1 and A=0, test d==Ndischarge, clear q if equal, then increment d. If q=1 and A=1, clear d. Output q. The threshold is tested before increment, including on the input-change call. For Ncharge=60, rising A at call 0 produces Q=1 at call 60, which is the 61st evaluator call including the edge. Zero charge delay turns on in that edge call. The microprocessor capacitor `0x14037b490` follows the same state recurrence. This Boolean charge/discharge state is not an electrical battery model.
138:Physical delay type 12: on input change, remember A and set counter c=0 without changing Q. On stable-input calls, if c<N, increment c; if the new c equals N, Q=A. Here N=trunc32(60*delay_seconds). Consequently a newly changed input needs N subsequent stable calls. Native edge case: N=0 does not take the update path, so this code leaves Q unchanged. That result follows from the explicit c<N guard, not the tooltip. Zero/negative UI setting constraints have not been traced. Evidence: entry `0x1403c521b` and its retained body through `0x1403c5283`.
140:Physical blinker type 11: Non=trunc32(60*field_6e0), Noff=trunc32(60*field_6dc). On input change, save A and clear c. Otherwise increment c and reset c=0 if c>=Non+Noff. Q=A AND c<Non. For positive integer durations and normal enabled simulation this gives Non on calls and Noff off calls per cycle. Both physical timer fields are serialized in the same gate object; the state assignment shows which is the on duration. Evidence: `0x1403c518e` through `0x1403c521a`.
142:Microprocessor blinker `0x14037bd60` differs: begin each call with Q=0; if A=0, c=0 and return. Let Non=trunc32(60*field_bc), Noff=trunc32(60*field_c0). If c<Non, set Q=1 and increment c. The later cycles have one on call and three off calls. Do not substitute the physical blinker recurrence for this one.
