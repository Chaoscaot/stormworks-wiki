67-### Candidate score and selection
68-
69:For positive signature `S` at physics target record `+0x8`, helper `0x140909e40`:
70-
71:1. Excludes self/owner records and several record types. Types 3, 5, 7 and 11 are excluded by the type masks in this helper. Another exclusion checks a linked object's `+0x2100` state. Its gameplay name remains open.
72-2. Tests the target position against five plane records. Equality to a plane fails the test.
73-3. Requires squared distance `<= R*R`.
74-4. Computes `score = (R / 10000) * S / distance` and requires `score > 0.025`.
75-
76:The arithmetic instructions include `0x14090a060`, `f3 41 0f 5e c6`, division by `10000`; `0x14090a06d`, `f3 41 0f 59 c1`, multiplication by signature; `0x14090a0a5`, `f2 0f 5e f0`, division by distance; and `0x14090a0ad`, `41 0f 2f f4`, comparison against `0.025`.
77-
78:For this candidate path, the score boundary is `distance < R*S/250`, with the separate inclusive cap `distance <= R`. This is an inverse-distance score, not a recovered random detection probability. There is no random draw in this helper. That rules out treating its `0.025` comparison as a probability roll. It does not prove that every target-producing subsystem is deterministic.
79-
80:The caller also processes non-physics target lists using related signature/distance scores, sorts candidates by descending score, and accepts at most eight results. The material-by-material meaning of the masks and query implementation were not fully decoded, so universal claims about terrain, water, glass or small obstacles remain open.

126-## Advanced sonar
127-
128:`radar_range` is reused as sonar part range `P`. The normal active candidate path in `0x1403bf8e0` reads positive target signature `S` from record `+0x8`, excludes self and linked special records, requires nonzero distance and `distance <= P`, and computes `P*S/(10000*distance)`. Candidate strength is compared strictly against `0.01` before final output. Thus the isolated candidate's score boundary is `distance < P*S/100`, subject to the cap `P`.
129-
130-This is not a complete hull-size law. The signature producer is the same unresolved kind of input as in radar. The sonar pipeline also handles other target lists and emitted pings. It merges close directions: if squared difference between normalized direction vectors is below `0.01`, it combines positions and directions with strength weighting and suppresses the merged record's independent strength. Candidates are sorted by strength, and no more than sixteen outputs are accepted. Crowded-target behavior therefore cannot be reduced to independent threshold tests.
131-
132:A rising active command resets timer `+0x378`. Later updates select stored targets whose distance is in `[timer * 12.333333, (timer+1) * 12.333333)`. Multiplication is at `0x1403c0d41`, bytes `f3 0f 59 35 23 f9 7e 00`. Upper-edge addition is at `0x1403c0d4c`, bytes `f3 0f 58 3d 18 f9 7e 00`. At 60 updates/s this advances approximately 740 metres of target distance per second. Interpreting that as a round trip at approximately 1480 m/s sound speed is an inference. The exact command-to-first-return tick phase is not asserted.
